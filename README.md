## Spring-Diary

## 프로젝트 소개  
취업을 준비중인 청년들을 위해 구인 공고 및 정부정책을 담아두기 위한 다이어리 입니다.  
URL : [https://www.spring-diary.xyz](https://www.spring-diary.xyz)

## 기술 스택
- MVC Pattern
- Springboot(3.4.4)
- Html5, CSS  
- Axios, AJAX  
- Github Actions(CI/CD)  
- MariaDB  
- AWS EC2, Gabia(도메인)  
- RESTful API, OAuth2(네이버)  

## 주요 기능  
- '온통청년' API를 활용한 정부정책 리스트 제공(지역별 분류 가능)
- '사람인' API를 활용한 구인 공고 리스트 제공(키워드 검색 가능)
- 즐겨찾기 기능을 활용한 공고 기간 확인용 달력
- 지원한 구인 공고 확인 및 간단한 메모기능 제공
- 사용자 편의를 위한 '네이버 소셜로그인' 기능
